# Server Bootstrap

**Автоматизированное развёртывание 3x-ui, Nginx и UFW на Ubuntu и Debian.**

## О проекте

Server Bootstrap представляет собой Bash-скрипт для быстрой установки и настройки прокси-сервера на базе:

- **3x-ui**: панель управления прокси-сервером.
- **Nginx**: обратный прокси и обработка TLS.
- **UFW**: межсетевой экран и контроль сетевого доступа.

Основная задача проекта заключается в минимизации количества публично доступных сервисов, ограничении прямого доступа к внутренним службам и упрощении развёртывания серверной инфраструктуры.

## Возможности

- Автоматическая установка и настройка 3x-ui, Nginx и UFW.
- Два режима развёртывания: локальный и удалённый.
- Автоматическое определение географического расположения сервера для формирования названий подключений.
- Проверка соответствия DNS A-записи публичному IPv4 целевого сервера.
- Поддержка wildcard TLS-сертификатов.
- Автоматическая настройка обратного прокси Nginx.
- Настройка правил UFW в зависимости от выбранных параметров установки.
- Автоматическое создание прокси-подключений.

### Поддерживаемые протоколы

При установке автоматически создаются три подключения:

| Протокол | Транспорт | Защита |
|---|---|---|
| VLESS | WebSocket | TLS |
| Hysteria2 | UDP | TLS |
| TUIC v5 | UDP | TLS |

## Режимы установки

### Локальная установка (Local)

Устанавливает и настраивает выбранные компоненты непосредственно на текущем сервере.

Используется собственная сетевая конфигурация сервера и выбранный способ получения TLS-сертификата.

### Удалённая установка (Remote)

Предназначена для развёртывания серверов с использованием центральной управляющей ноды и существующего wildcard TLS-сертификата.

Центральная нода передаёт необходимые файлы установки и сертификат на целевой сервер через SSH.

Это позволяет развёртывать несколько серверов с использованием общего wildcard-сертификата без необходимости выпуска отдельного сертификата для каждой ноды.

## Подписка 3x-ui

Подписка 3x-ui остаётся включённой независимо от выбранных параметров установки.

В зависимости от конфигурации используется один из двух вариантов доступа:

- **Reverse proxy включён:** адреса подписки доступны через Nginx.
- **Reverse proxy выключен:** прямой внешний доступ к порту подписки ограничивается правилами UFW.

## Системные требования

### Поддерживаемые операционные системы

- Ubuntu
- Debian

### Зависимости

Скрипт использует следующие системные утилиты и пакеты:

- `bash`
- `curl`
- `ca-certificates`
- `openssl`
- `sqlite3`
- `python3`
- `gnupg2`
- `lsb-release`
- `ufw`
- `systemd`
- `iproute2`
- `gawk`
- `sed`
- `coreutils`

Дополнительные зависимости, необходимые для установки Nginx, устанавливаются автоматически.

## Безопасность

Проект ориентирован на сокращение количества публично доступных сервисов и уменьшение поверхности атаки.

В конфигурации предусмотрены:

- Ограничение доступа к интерфейсам управления.
- Контроль сетевого доступа средствами UFW.
- Публикация выбранных сервисов через обратный прокси Nginx.
- По возможности отсутствие прямого публичного доступа к внутренним сервисам.
- TLS-шифрование поддерживаемых подключений.

**Примечание:** никакая конфигурация не гарантирует полной невидимости для сетевых сканеров. Фактический уровень защиты зависит от сетевой доступности, настроек firewall, конфигурации служб и инфраструктуры хостинга.
